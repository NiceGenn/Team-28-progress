# Штаб проекта «Точка перемен»

Рабочая страница проекта бережливого управления администрации
Благовещенского муниципального округа — для команды проекта и коллег.

**Открыть:** https://nicegenn.github.io/Team-28-progress/

## Что на странице

- где проект сейчас на ленте времени и какой этап идёт;
- что делать на текущей неделе, с пояснением, зачем каждая задача
  и от кого она зависит;
- статусы документов пакета: карточка, карты процесса, план мероприятий,
  отчёт, стандарт, презентация, конкурсные материалы;
- самооценка по критериям конкурса «Команда-28»;
- что осталось уточнить.

## Как этим пользоваться

Отметки, статусы, даты и заметки сохраняются **в браузере того, кто их ставит** —
у каждого свои, между людьми не синхронизируются. Это личный рабочий блокнот
поверх общей картины, а не общая доска.

Содержание страницы обновляет руководитель проекта. Если что-то устарело или
нужно добавить — скажите ему.

## Что в репозитории

| Файл | Что это |
|---|---|
| `index.html` | сама страница, один самодостаточный файл |

Проектные документы — карточка, карты процесса, план мероприятий, отчёт —
ведутся отдельно и здесь не публикуются.
